# New Nigeria Unity — Official Website

The official homepage for New Nigeria Unity (NNU), a non-partisan, 
citizen-led grassroots peace and unity movement operating across 
all 36 Nigerian states and the FCT.

🌐 Live site: https://newnigeriaunity.org
📘 Facebook: https://www.facebook.com/share/19BQYxqmRt/

## About This Site
Single self-contained HTML file (`index.html`) — all images are 
embedded directly in the file, so no separate assets folder is needed.

## Campaign
"One Handshake at a Time" — launching August 1, 2026, featuring the 
36-episode Unity Stories Across Nigeria series.

## Updating the Site
To publish changes:
1. Replace `index.html` in this repo with the updated version
2. GitHub Pages will automatically redeploy within a few minutes
